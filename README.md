# mobileappskill

**Created by: CGST vala Aditya**

A Claude skill that guides non-coders through planning, designing and building an **Android + iOS app** with Claude: a stage-by-stage checklist, Apple HIG and Material 3 design rules, App Store and Google Play requirements, India's DPDP Act, security basics, and a lean Claude tool setup.

## What's inside
- `mobileappskill/SKILL.md`: the skill

## Install
**Claude.ai / desktop app:** Settings → Capabilities → Skills → upload the `mobileappskill` folder (zipped).

**Claude Code:** copy the `mobileappskill` folder into `~/.claude/skills/` (or `.claude/skills/` in a project).

## When it runs
Only when you clearly say you want to build, start or design a mobile app (e.g. "I want to build an app"). It stays idle in routine chats to save tokens. You can also call it directly with `/mobileappskill`.

## Note
Facts are current as of November 2026. Fees, store rules and legal dates change, so the skill re-checks them before quoting. This is not legal advice.
